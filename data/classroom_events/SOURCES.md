# Classroom Relational-Event Data Sources

These unmodified files reproduce the classroom data used in Chapter 13, Part 4
of the NetworkAnalysisR online tutorial:

https://inarwhal.github.io/NetworkAnalysisR-book/ch13-Relational-Event-Models-R.html

Downloaded source files:

- `class_interactions_date1.txt`  
  https://github.com/JeffreyAlanSmith/Integrated_Network_Science/raw/master/data/class_interactions_date1.txt
- `class_interactions_date2.txt`  
  https://github.com/JeffreyAlanSmith/Integrated_Network_Science/raw/master/data/class_interactions_date2.txt
- `class_attributes.txt`  
  https://github.com/JeffreyAlanSmith/Integrated_Network_Science/raw/master/data/class_attributes.txt
- `class_seating_date1.txt`  
  https://github.com/JeffreyAlanSmith/Integrated_Network_Science/raw/master/data/class_seating_date1.txt
- `class_seating_date2.txt`  
  https://github.com/JeffreyAlanSmith/Integrated_Network_Science/raw/master/data/class_seating_date2.txt
- `class_edgelist_sem2.txt`  
  https://github.com/JeffreyAlanSmith/Integrated_Network_Science/raw/master/data/class_edgelist_sem2.txt

The local example in `examples/classroom_event_study.py` follows
the tutorial's data-preparation logic and model families.
